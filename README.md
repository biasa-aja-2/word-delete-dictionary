The one word I'd delete from the dictionary: **queue**. It is a single letter, "q", smuggling four silent letters behind it. Nobody pronounces the "ueue". Delete the word and the language loses nothing — everyone at the back of the line just writes "q".

## Run it

```sh
python3 main.py
```

Writes the single word `queue` to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
